# ARI SMART RO v1.0.21 — Offline Field Work

- Previously downloaded engineer jobs remain available when mobile data or internet is unavailable.
- Job status transitions are stored locally during outages and automatically synchronized when connectivity returns.
- GPS coordinates are captured from the phone and queued locally if the server cannot be reached.
- Before/after job photos are copied into durable app storage and uploaded later.
- Customer signatures are retained locally until synchronization succeeds.
- Service/complaint/payment/removal jobs can be completed from the field without an active internet connection after the job has been downloaded.
- Installation details can be saved offline; server-dependent OTP generation/verification still requires connectivity.
- Existing v1.0.19 bilingual training/compliance and v1.0.20 Caller Command Center remain included.
