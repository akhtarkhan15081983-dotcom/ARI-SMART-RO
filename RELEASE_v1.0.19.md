# ARI SMART RO v1.0.19

## Bilingual professional training

- All six Customer Respect & Relationship Excellence lessons now include English and clear Hindi guidance.
- Four bundled, ARI-branded Hindi scenario videos cover respect, LAST de-escalation, service recovery and professional customer PR.
- Video lessons must be watched fully before the employee can mark them complete.
- Existing compliance rules remain: 80% quiz pass, 7-day deadline, 2-day grace and Admin-reviewed ₹100 penalty draft.

## Trusted attendance time and checkout reminders

- Check-in and check-out times are displayed from the server-issued timezone-aware timestamps.
- The API returns the authoritative server time and checkout reminder time calculated from the current HR daily-work-hours policy.
- A high-priority Hindi/English local notification reminds checked-in employees to check out.
- The Attendance screen keeps a visible Checkout Pending card until checkout succeeds.
- Failed checkout responses are no longer shown as success; the server error is displayed and the reminder stays active.
