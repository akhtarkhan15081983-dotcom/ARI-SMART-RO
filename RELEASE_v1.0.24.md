# ARI SMART RO v1.0.24 — Shareable PDF Training Certificate

- Adds a branded landscape A4 PDF for every issued ARI Professional Training Certificate.
- PDF includes employee name and ID, training title, quiz score, trainer average, weighted final score, issue date, validity date, certificate number and verification code.
- Embedded QR opens the public certificate verification endpoint.
- Certificate status is rendered as VALID, EXPIRED or REVOKED.
- Employee Training shows a View / Share PDF Certificate action.
- Automated backend test confirms a real PDF response is generated.
- Retains all v1.0.23 certification rules and all v1.0.22 training/offline features.
